# ORIANA — Guide to the Guideline Suite

**Version 1.0 · July 2026 · Prepared for Chesa**

This is the index and operating manual for the Oriana guideline suite. Six documents plus one machine-readable design spec govern the brand. Each is written to be used weekly, not admired annually.

| # | Document | Governs | Read it when |
|---|---|---|---|
| 01 | **Brand Guidelines** | Name, architecture, wordmark, colour, type, imagery rules, applications | Before creating anything visual, briefing any designer or printer |
| 02 | **Voice & Messaging** | The three registers, vocabulary, message hierarchy, copy patterns, microcopy | Before writing anything — captions, WhatsApp templates, web copy |
| 03 | **Marketing Guidelines** | Funnel phases, channel roles, pricing conduct, referral engine, KPIs, time budget | Monthly review; before any new marketing idea |
| 04 | **Social Media Playbook** | Profile standards, four pillars, cadence, templates, Stories, DMs, model era | Weekly batching session |
| 05 | **Client Experience** | The journey map, studio standards, policies, client records, recovery, rebooking | Before opening; retrain against it quarterly |
| 06 | **Photography Standards** | The fixed corner, standard shots, the grade, composition, video, library | When building the photo corner; whenever an image looks "off" |
| — | **DESIGN.md** | Machine-readable design tokens + rationale for the website and any future digital build | Handing design to any developer or agent |

## The five rules that outrank everything

If the suite ever feels like too much, these five carry 90% of the value:

1. **Retention is the brand.** The rebooking rate outranks every other number, and every guideline bends toward it.
2. **One setup, one grade, forever.** The fixed photo corner and the Oriana Gold preset are what make one artist look like a brand.
3. **Noticed, not announced.** No urgency, no discounts, no shouting — in design, in copy, in the room.
4. **Prices plain, proof public.** State prices; show week-three retention; refuse work honestly.
5. **Oriana is the world, Chesa is the trust.** The brand speaks editorially; the artist speaks as "I"; never blur them in one sentence.

## Change control

These documents are living but not casual: change them deliberately, version them (1.1, 1.2 …), and never mid-week. Anything that contradicts the Brand & Brand Strategy (v3) is a strategy conversation first, a guideline edit second.
